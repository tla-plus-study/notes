\section*{What stood out}
\begin{itemize}
    \item in TLA+ every value is a set. 
    \item TLA+ does not specify what set elements are and cannot evaluate expressions like $42 \in ABC$.
    \item The scope of $\forall$ and $\exists$ extends as far as possible in TLA+, unless ended by parentheses or the end of a list item such as $\land$ or $\lor$.
\end{itemize}
